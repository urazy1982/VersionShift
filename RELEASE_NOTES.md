## Check this release (no experiments, under a minute)

```bash
pip install -r requirements.txt
python3 paper/verify_results.py                                           # original study: hashes, A/A identity, recomputation
python3 paper/reproduce_paper.py                                          # every number and figure of the original analysis
python3 postreview/verify_postreview.py --zip VersionShift_replication.zip   # post-review G0–G3 analyses
```

All three should end with `ALL CHECKS PASSED` or write their outputs without error.

## Contents

- **Original study** (`project/`, `pipeline/`, `results/`, `paper/`): frozen protocol v2.2.5 plus the pre-run amendment v2.2.6. Fold-level results for 63 tasks, six estimators, two upgrades and four policies. Environment lock files and provenance. Scripts that reproduce every number and figure of the original analysis.
- **Post-review evidence** (`postreview/`): independent recomputation, restoration of old effective defaults, boosting interventions, bootstrap and winner-margin sensitivity, and the corrected six-estimator explicit map E2. Includes all raw outputs (1,568 files with checksums) and a verifier that re-runs each read-only analysis against them.

## Not included

- **OpenML-CC18 datasets.** Rebuild them with `controller.py freeze` (README, step 2); `pipeline/finish/check_plan_cache.py` confirms that they match the frozen hashes.
- **The per-release Python environments.** Rebuild them with `project/crossversion/build_envs.sh` and compare with `results/envs/*/lock.txt`.

## Known issues

These are documented in the README and in `postreview/README.md`; none of them changes a reported number.
- **`combine()` re-run.** The frozen kit's `combine()` fails when `analyze` is re-run. It is worked around by `pipeline/addons/vs_finish_analyze.py`.
- **Lens S on E0.** Lens S is not estimable on E0. Instead, policy S is shown to equal policy D bitwise on all 22,680 folds.
- **G2 A/B/C parsing.** `postreview/code/G2_COMPARE/G2_compare_ABC.py` needed a one-line parsing fix (`int(float(...))`) to read the merged result file.
- **G0-D exit code.** G0-D exits with code 3 because its built-in check expects 165 sign changes and counts 164 strict reversals. The paper reports both.
