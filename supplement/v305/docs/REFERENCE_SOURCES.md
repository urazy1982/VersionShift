# Literature and primary documentation sources (verified links, November 2026)

1. Montandon, J. E., Silva, L. L., Politowski, C., Prates, D., Bonifácio, A. D. B., & El Boussaidi, G. (2025). **Unboxing Default Argument Breaking Changes in 1 + 2 data science libraries.** *Journal of Systems and Software*, 229, 112460. https://doi.org/10.1016/j.jss.2025.112460. Measures static default-argument breaking changes and client exposure; VersionShift measures downstream controlled changes in comparative ML evidence.
2. Bouthillier, X., et al. (2021). **Accounting for Variance in Machine Learning Benchmarks.** *Proceedings of Machine Learning and Systems*, 3. https://proceedings.mlsys.org/paper_files/paper/2021/hash/0184b0cd3cfb185989f858a1d9f5c1eb-Abstract.html. Benchmark variance and comparison reliability, not isolated library version interventions.
3. Bischl, B., et al. (2019). **OpenML Benchmarking Suites.** https://arxiv.org/abs/1708.03731. CC18 benchmark suite.
4. Jin, B., Wang, K., & Nie, P. (2026). **Automated Modernization of Machine Learning Engineering Notebooks for Reproducibility.** *Proceedings of the ACM on Software Engineering*, 3(ISSTA), ISSTA075. https://doi.org/10.1145/3832166 (preprint: https://arxiv.org/abs/2602.07195). Environment erosion and executable notebooks.
5. Idowu, S., Osman, O., Strüber, D., & Berger, T. (2024). **Machine learning experiment management tools: a mixed-methods empirical study.** *Empirical Software Engineering*, 29, Article 74. https://doi.org/10.1007/s10664-024-10444-w.
